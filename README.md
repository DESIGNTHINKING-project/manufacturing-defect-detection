# Manufacturing Image Processing Project

## Overview
This project uses Python to load and display manufacturing images as an initial step toward image processing and defect detection.

## Requirements
- Python 3
- OpenCV
- Matplotlib
- NumPy

## Setup Instructions

1. Install Python.
2. Open Command Prompt in the project folder.
3. Create a virtual environment:

   `python -m venv .venv`

4. Activate the environment on Windows:

   `.venv\Scripts\activate`

5. Install the required libraries:

   `python -m pip install -r requirements.txt`

## Run the Program

Place a sample image named `sample.jpg` in the project folder.

Run:

`python main.py`
